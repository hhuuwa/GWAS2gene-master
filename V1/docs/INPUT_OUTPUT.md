## Annotation enrichment and recommendation

`V1/bin/annotate_recommendations.py` annotates Step2 result rows with `basic_data/all.locus_brief_info.7.0.with_keyword.tsv` and writes one `.annotated.tsv` file per input. The added row-level fields are:

- `Annotation_locus`
- `Symbol`
- `Keyword`
- `Locus_annotation`
- `Locus_is_TE`
- `Locus_is_expressed`
- `Locus_is_representative`
- `Recommendation_score`
- `Recommendation_reason`

The recommender also writes `<trait>_top10_candidate_genes.tsv`. It ranks genes by the final Step2 score plus explicit bonuses for multi-mode support, locus keyword evidence, Symbol annotation, high-impact SIFT/INDEL/SV evidence, and genotype-match evidence.

## FarmCPU significant-site filtering

Full FarmCPU CSV inputs are filtered before peak merging. The default threshold is `p <= 1e-5`, and can be changed with:

- `V1/expand/Select_FarmCPU_Peak.py <trait> --p-threshold <value>`
- `V1/bin/riceg2g.py --farmcpu-p-threshold <value>`
- `V1/bin/run_v1.ps1 -FarmCpuPThreshold <value>`

The filtered significant-site table is written as `<trait>.FarmCPU.significant.tsv`.

## Biological interpretation note

`RAP_Step2_*.FarmCPUpeak_info` is the final candidate-gene prioritization table with integrated evidence:

- association strength (`Score_peak`)
- annotation support (`Score_annotate`)
- expression specificity (`Score_expression`)
- variant impact (`SIFT/INDEL/SV`)
