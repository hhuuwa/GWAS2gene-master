# Input/Output Specification (V1)

## Core inputs

- `data/farmCPU/<trait>.MLM.csv` or `data/farmCPU/<trait>.MLM/<trait>.MLM.csv`
- `data/WinQTLcart/<AREA>_Nam1-C.qrt` ... `Nam15-C.qrt`
- `data/WinQTLcart/N1.bin.list.map` ... `N15.bin.list.map`
- `basic_data/Rice_IRGSP-1.0.gff3`
- `basic_data/Rice_MSUv7.gff3` or `basic_data/Rice_MSUv7/Rice_MSUv7.gff3`
- `RAP_<trait>.FarmCPUpeak_info` (used by current V1 wrapper for step1 compatibility)

## Main outputs

- `<trait>.MLM.peak`
- `<trait>.winqtlcart.peak`
- `<trait>_NAM_LOD_geno.info`
- `<trait>_NAM_LOD_geno_rap.info`
- `RAP_Step2_<step2_trait>.FarmCPUpeak_info`

## Visualization outputs (optional)

Generated by `V1/bin/make_demo_assets.py`:

- `V1/demo/results/top_candidates.tsv`
- `V1/demo/results/qtl_summary.tsv`
- `V1/demo/results/top_candidates.svg`
- `V1/demo/results/score_components_heatmap.svg`
- `V1/demo/results/qtl_max_score.svg`
- `V1/demo/results/report.html`

## Annotation enrichment

If `V1/source/rice_new_keyword.txt` is present, the following fields are added to summary outputs:

- `Symbol`
- `Keyword`
- `Best_Gene_Symbol`
- `Best_Gene_Keyword`

## Biological interpretation note

`RAP_Step2_*.FarmCPUpeak_info` is the final candidate-gene prioritization table with integrated evidence:

- association strength (`Score_peak`)
- annotation support (`Score_annotate`)
- expression specificity (`Score_expression`)
- variant impact (`SIFT/INDEL/SV`)
